## ⚡ О проекте

**TravelRadar** — это интерактивный сервис для путешественников, позволяющий найти самые выгодные билеты, когда бюджет ограничен или когда хочется улететь «куда угодно дешевле всего».

### 🌟 Ключевые возможности:
- 🌍 **Поиск «Куда угодно» (Anywhere Search):** выберите город вылета (Москва, СПб, Минск, Тбилиси, Ереван, Стамбул и др.) и получайте подборку направлений по минимальной цене.
- 💵 **Мультивалютность:** моментальное переключение между RUB (₽), USD ($), EUR (€), BYN (Br) и KZT (₸).
- 📅 **Интерактивный календарь цен:** прогноз стоимости перелетов на 28 дней вперед с цветовой тепловой картой суперцен.
- 🧮 **Калькулятор бюджета поездки под ключ:** расчет полной стоимости (перелет туда-обратно + проживание в отеле/хостеле + суточные расходы).
- ⚡ **Скрытые лоукост-хаки:** проверенные схемы пересадок через транзитные хабы (Ереван, Кутаиси, Стамбул), позволяющие экономить до 70% на перелетах в Европу и Азию.
- 🚫 **Безвизовый фильтр:** мгновенная фильтрация стран, куда не нужна виза или оформляется онлайн/по прибытии.
- ❤️ **Избранное (Wishlist):** сохранение понравившихся направлений прямо в браузере.
- 🔔 **Радар уведомлений:** подписка на отслеживание резких падений тарифов.
- ✈️ **Прямые ссылки на покупку:** переход в один клик к бронированию билетов без наценок.

## 🛠 Технологический стек

- **Frontend:** React 19, Vite, Tailwind CSS
- **Иконки & Анимации:** Lucide React, Canvas Confetti
- **Деплой & Хостинг:** GitHub Pages + GitHub Actions CI/CD

---

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/oktinsfly/travel-radar.git
   cd travel-radar
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

4. Соберите production-версию:
   ```bash
   npm run build
   ```
